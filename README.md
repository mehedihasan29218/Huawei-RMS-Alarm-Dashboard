# Huawei-RMS-Alarm-Dashboard

## 📌 Project Overview
This project focuses on analyzing telecom tower alarms from Huawei RMS by automating alarm data extraction through RPA and transforming the data using Power BI Power Query. The dashboard applies DAX calculations to generate KPIs and deliver actionable insights for monitoring network performance, alarm trends, and operational efficiency.

## 🚀 Key Features
- Automated telecom alarm data extraction using RPA
- Huawei RMS alarm monitoring and analysis
- Data transformation and cleaning with Power Query
- KPI generation using DAX measures
- Interactive Power BI dashboard with drill-down analysis
- Alarm trend and frequency monitoring
- Tower-wise and region-wise alarm analysis
- Operational performance tracking


## 📊 Dashboard Insights
- Most frequent telecom alarms
- Critical alarm trend analysis
- Tower-wise alarm distribution
- Regional performance comparison
- Alarm resolution monitoring
- Network issue identification and tracking
- Historical alarm pattern analysis
